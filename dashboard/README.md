# ReoVault dashboard

The web UI for ReoVault: a SvelteKit single-page app (Svelte 5, Tailwind v4,
shadcn-svelte) on top of the `/api/v1` JSON API. It is built to static files
in the Docker image's build stage and served by the ReoVault daemon itself.

Development setup, the API type generation step and the UI design rules are
in the repository's [CONTRIBUTING.md](../CONTRIBUTING.md#the-dashboard).
